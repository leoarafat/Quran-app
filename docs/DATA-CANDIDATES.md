# নতুন ডেটার উৎস যাচাই (২০২৬-১১-২৫)

এটি আইনি পরামর্শ নয়। **কোনো ডেটা ফাইল প্রজেক্টে নামানো হয়নি।** দেখা হয়েছে: অফিসিয়াল পাতা, তালিকার তথ্য, হেডার, আর QuranEnc API-র সূরা ১-এর নমুনা (সেভ করা হয়নি; QuranEnc-এর অনুবাদ-তালিকা শুধু scratchpad-এ)। ওয়েবপাতার অনেকগুলো স্বয়ংক্রিয় সহকারী পড়েছে; ব্যবহারের আগে শর্তের পাতা নিজে খুলে মিলিয়ে নিন।

## খ. শর্ত অনুকূল, কিন্তু প্রকাশের আগে একটি তথ্য বাকি

| কী | অবস্থা |
|---|---|
| **বাংলা তাফসির: আল-মুখতাসার** (`bengali_mokhtasar`) | API সূরা ১-এ ৭টি আয়াতসহ সাড়া দিয়েছে। QuranEnc-এর ৭ শর্ত সব অনুবাদের জন্য সাধারণ। **সমস্যা:** `/translations/list` ও `/list/bn`-এ এটি নেই, ভার্সন নম্বর পাওয়া যায়নি (শর্ত ৩), অনুবাদক/পর্যালোচকের নাম পাতায় নেই। CSV লিংক ফাইল না দিয়ে ফাঁকা সাড়া দিয়েছে। মোট সাইজ অজানা (১১৪টি API অনুরোধে নামাতে হবে, বর্তমান অনুবাদের মতো) |
| বাংলা অনুবাদ: আবু বকর জাকারিয়া (`bengali_zakaria`) | আগের মতোই: API সাড়া দেয়, অফিসিয়াল তালিকায় নেই |

করণীয়: QuranEnc-কে ভার্সন নম্বর ও অনুবাদক/পর্যালোচকের নাম জিজ্ঞেস করা। HadeethEnc-এর বাকি প্রশ্নের সাথে একই মেইলে করা যায়।

শর্তে বাণিজ্যিক ব্যবহার নিয়ে কিছু বলা নেই।

## গ. লিখিত অনুমতি ছাড়া নয়

| কী | কেন |
|---|---|
| তাফসির ইবনে কাসির (বাংলা), আহসানুল বায়ান, ফাতহুল মাজীদ, জাকারিয়া | [QUL](https://qul.tarteel.ai/resources/tafsir)-এ আছে, কিন্তু পাতায় স্বত্বাধিকারী বা লাইসেন্স লেখা নেই। QUL নিজেই বলে প্রতিটির স্বত্ব আলাদা। [tafsir_api](https://github.com/spa5k/tafsir_api)-র MIT লেবেল তৃতীয় পক্ষের লেখার অনুমতি বলে ধরা যায় না (ওই পাতায় ইবনে কাসিরের লেখক হিসেবে "Tawheed Publication") |
| শব্দে শব্দে বাংলা অর্থ | QUL-এ "Bengali wbw translation" (resources/translation/94) দেখা গেছে; স্বত্ব ও লাইসেন্স লেখা নেই। এন্ট্রিটি পাতার সারাংশ থেকে পাওয়া, নিজে মিলিয়ে নিতে হবে। Quran Foundation API-র শর্তে স্ট্যাটিক বান্ডল নিষেধ। শব্দে শব্দে **উচ্চারণের** কোনো উৎস পাওয়া যায়নি |
| পূর্ণ হাদিস গ্রন্থ (বাংলা) | [fawazahmed0](https://github.com/fawazahmed0/hadith-api)-এর `ben-*` সংস্করণগুলোর তথ্যে অনুবাদক **"Unknown"**, উৎস ফাঁকা (নববীর ৪০-এ শুধু মূল লেখকের নাম)। রিপোর Unlicense অনুবাদকের অনুমতি নয়। **ব্যবহার করা উচিত নয়।** sunnah.com ও hadithbd.com স্বয়ংক্রিয় অনুরোধ ফিরিয়ে দিয়েছে (৪০৩), শর্ত পড়া যায়নি |
| তিলাওয়াত অডিও (চলমান) | [everyayah.com](https://everyayah.com/)-এর দেখা দুই পাতায় কোনো শর্ত বা অনুমতির কথা নেই। এখন শুধু স্ট্রিম হয় (অফলাইনে সেভের সুবিধাও আছে)। লাইভের আগে অনুমতি চাওয়া দরকার |
| ৯৯ নাম (বাংলা অর্থসহ) | অনুমতিসহ উৎস পাওয়া যায়নি (HadeethEnc হোমপেজে নেই, QUL-এর বিভাগে নেই, IslamHouse-এর ভেতরে খোঁজা হয়নি) |
| কিং ফাহদ কমপ্লেক্সের ফন্ট | ফন্ট পাতা অন্য ঠিকানায় পাঠিয়ে দেয়; শর্ত পড়া হয়নি |

## ঘ. নিয়ম মেনে করা যায়, তবে বিষয়বস্তু মালিককে দিতে হবে

- **ভিডিও:** ইউটিউব এমবেড করা যায় [এই নিয়মে](https://developers.google.com/youtube/terms/required-minimum-functionality): প্লেয়ার অন্তত ২০০×২০০, তার ওপর কিছু বসানো যাবে না, Referer আটকানো যাবে না। অফলাইনে চলবে না। **কোন চ্যানেল বা ভিডিও**, তা মালিক ও আলেম ঠিক করবেন।
- **OSM ম্যাপ-টাইল:** নাম উল্লেখ বাধ্যতামূলক; [টাইল-নীতিতে](https://operations.osmfoundation.org/policies/tiles/) অফলাইন সেভ ও আগাম নামানো নিষেধ।

## যা খোঁজা হয়নি
শানে নুযুলের উৎস, বিষয়ভিত্তিক আয়াত-সূচি, ইসলামিক বই, বাংলা লেকচার, অডিওবুক ও নাশিদ।

## প্রস্তাব (অনুমতি পেলে এই ক্রমে)
1. ইংরেজি অনুবাদ `english_saheeh` (শর্ত ও ভার্সন দুটোই আছে)
2. আজানের একটি অডিও ও একটি বাড়তি আরবি ফন্ট
3. আল-মুখতাসার তাফসির: নামিয়ে স্থানীয়ভাবে বানানো যায়; **লাইভে ভার্সন নিশ্চিত হওয়ার পর**
