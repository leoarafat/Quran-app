# অন্য অ্যাপের লিংক পেলে যা করবেন (নামাজ শিক্ষার কাজ থেকে শেখা, ২০২৬-১১-২৮)

মালিক নতুন window-তে একটি Play Store লিংক দেবেন (বলেছেন, তাতে প্রায় ১ লাখ হাদিস আছে)। লক্ষ্য: অ্যাপে **যা যা আছে তার সব বিষয় ও ফিচার**
নূর কুরআনে আনা, যত দ্রুত সম্ভব।

## সীমা (শুরুতেই মালিককে এক-দুই লাইনে জানান)
- ওই অ্যাপের লেখা, অনুবাদ, ছবি, অডিও **কপি নয়**। APK খুলে বা ডেটাবেস/API থেকে ডেটা বের করা (scrape, decompile, bulk screenshot-OCR) **নয়**।
  নূর কুরআন লাইভ পাবলিক সাইট; "ব্যক্তিগত ব্যবহার" বলে এটি বদলায় না (মালিককে আগে বুঝিয়ে বলা হয়েছে)।
- ব্যতিক্রম: ডেভেলপার/স্বত্বাধিকারীর **লিখিত অনুমতি বা তাঁর দেওয়া export ফাইল** থাকলে সেটি সরাসরি import। এটিই সবচেয়ে দ্রুত পথ।
- দেখা যাবে: বিভাগ, মেনু, বিষয়ের শিরোনাম, সংখ্যা, ফিচার ও ব্যবহারের ধারা।

## দ্রুত পদ্ধতি
0. অ্যাপ ঘোরার সময় তার ডিজাইন প্যাটার্ন ও রং `docs/DESIGN-REFERENCES.md`-তে যোগ করুন (শুধু নোট; মালিক না বলা পর্যন্ত চেহারা বদল নয়)।
1. **পড়ুন:** `docs/RESUME.md`, `docs/DATA-SOURCES.md`, `docs/DATA-CANDIDATES.md`, `docs/NAMAZ-TOPICS.md`।
2. **ইনভেন্টরি:** emulator-এ অ্যাপ ঘুরে বিভাগ → উপবিভাগ → ফিচার → আনুমানিক সংখ্যা। শুধু শিরোনাম। `docs/<APP>-TOPICS.md`-তে ✅🟡❌ মিলিয়ে ব্যাচে ভাগ।
3. **ডেটা আলাদা, ফিচার আলাদা।** ফিচার (খোঁজা, বিষয়সূচি, বুকমার্ক, শেয়ার, অফলাইন) নিজেদের কোডে সাথে সাথে বানানো যায়; ডেটার জন্য অপেক্ষা লাগে না।
4. **বড় ডেটা (হাদিস) কখনো হাতে লেখা বা মডেল দিয়ে বানানো নয়।** অনুমোদিত উৎস থেকে স্ক্রিপ্টে import:
   - এখন আছে HadeethEnc বাংলা (বিল্ডে ১৯২২টি; `scripts/build-hadith.mjs`, `verify-hadith.mjs`)।
   - পূর্ণ গ্রন্থের **বাংলা** অনুবাদ: ২০২৬-১১-২৫-এর যাচাইয়ে অনুমতিসহ উৎস পাওয়া যায়নি (`DATA-CANDIDATES.md` গ)। নতুন করে খুঁজুন
     (প্রকাশক/অনুবাদকের অনুমতি, QuranEnc/HadeethEnc টিম, শর্ত-লেখা open dataset)। শর্ত না পড়ে কিছু যোগ নয়।
   - আরবি মূল পাঠ প্রাচীন, তবে প্রতিটি ডিজিটাল সংস্করণের শর্ত আলাদা করে দেখুন। ডাউনলোডের আগে ফাইল, উৎস, সাইজ জানিয়ে অনুমতি নিন।
   - ১ লাখ সংখ্যায় পৌঁছানো যাবে এমন প্রতিশ্রুতি দেবেন না; উৎস যাচাইয়ের পরে আসল সংখ্যা জানান।
5. **১ লাখ রেকর্ডের কারিগরি দিক (আগে ডিজাইন করুন):** এখনকার static export-এ প্রতি হাদিসে আলাদা ফাইল/পাতা চলবে না
   (বিল্ড সময়, Vercel ফাইল-সীমা, অফলাইন সাইজ)। বই/অধ্যায় ধরে chunk করা JSON, চাহিদামতো লোড, সার্চ-ইনডেক্স ভাগ করা (বা সার্ভার/DB সার্চ),
   অফলাইনে বই ধরে ঐচ্ছিক ডাউনলোড। আগে কয়েক হাজার রেকর্ডে বিল্ড সাইজ ও সার্চের গতি মাপুন। প্রতিটি রেকর্ডে বই, নম্বর, মান (গ্রেড), উৎস, ভার্সন;
   গণনা ও নমুনা যাচাইয়ের টেস্ট। দুর্বল/অস্পষ্ট মান আগের নিয়মে আটকান।
6. **নিজেদের লেখা বিষয়বস্তু** (নামাজ শিক্ষার মতো): ব্যাচে লিখুন; আরবি শুধু স্ক্রিপ্টে যাচাই করা ফাইল থেকে কাটুন
   (`scripts/extract-namaz-duas.py`); না পেলে ফাঁকা রেখে জানান; ভিত্তিহীন আমল বাদ; `ALEM-REVIEW.md` হালনাগাদ।
7. **নতুন যা যোগ হবে তাতে "নতুন" ব্যাজ** (মালিকের নিয়ম): `isNew` + `src/components/NewBadge.tsx`।
8. প্রতি ব্যাচে: `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build`, `scripts/dev/shot.mjs` (৩২০/৩৯০/১২৮০px), ছবি চোখে দেখা, `RESUME.md`।
   কমিট/পুশ শুধু মালিকের কথায় (`main` পুশ = লাইভ)।

## Android emulator (তৈরি আছে)
- SDK `~/Library/Android/sdk`, Java `/opt/homebrew/opt/openjdk@17`, AVD `nq_ref` (Play Store-সহ; মালিকের Google অ্যাকাউন্টে সাইন-ইন করা।
  ওই অ্যাকাউন্টের অন্য কিছুতে হাত দেবেন না)। কাজ পুরো শেষ হলে মালিককে মোছার কথা মনে করান।
- চালু (background-এ): `ANDROID_HOME=~/Library/Android/sdk ~/Library/Android/sdk/emulator/emulator -avd nq_ref -no-snapshot-save -no-boot-anim`
- অ্যাপের পাতা খোলা: `adb shell am start -a android.intent.action.VIEW -d "https://play.google.com/store/apps/details?id=<ID>" com.android.vending`
  তারপর Install-এ ট্যাপ (ফ্রি অ্যাপ হলে; কেনাকাটা/সাবস্ক্রিপশন নয়)। অনুমতি-প্রম্পট deny, বিজ্ঞাপনে ট্যাপ নয়।
- স্ক্রিনশট/ট্যাপ: `sh scripts/dev/emu-shot.sh <wait-sec> [adb shell args]` → `$TMPDIR/emu/s.png` (অর্ধেক সাইজ; ট্যাপের স্থানাঙ্ক ×২)।
- অ্যানিমেশন থাকা পাতায় `uiautomator dump` ব্যর্থ হয় ("could not get idle state"); স্ক্রিনশট দেখুন।
- আগে পিছনে (back = `input keyevent 4`), পরের সারি ট্যাপ; একটি কমান্ডে কয়েকটি স্ক্রিনশট নিয়ে পরে একসাথে পড়লে দ্রুত হয়।
