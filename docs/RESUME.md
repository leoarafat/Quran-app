# এখান থেকে শুরু করুন

মালিক যখন বলবেন **"noor-quran যেখান থেকে থেমেছিলে সেখান থেকে শুরু করো"**, তখন:
1. এই ফাইল পড়ুন, তারপর `docs/PROGRESS.md` (ইতিহাস)। দরকারে `docs/PLAN.md`, `docs/DATA-SOURCES.md`।
2. `git status` ও `git log` দেখুন (মালিক কাজের মাঝে নিজে কমিট করেন), তারপর `npm test`।
3. নিচের "এখন কোথায়" থেকে পরের কাজ শুরু করুন। আবার অনুমতি চাওয়ার দরকার নেই, তবে নিচের "যা না জিজ্ঞেস করে করা যাবে না" মানবেন।

> **প্রতিটি কাজ শেষে এই ফাইলের "এখন কোথায়" অংশ হালনাগাদ করতে হবে।**

## এখন কোথায় (২০২৬-১১-২৫)

**সর্বশেষ শেষ হয়েছে:** অ্যাডভান্সড সার্চ ও বুকমার্ক (কোড, টেস্ট, বিল্ড, ব্রাউজার যাচাই সব ✅)। অসমাপ্ত কোনো কোড নেই।

**তৈরি আছে:** স্বাগতম, হোম (আসল নামাজের সময়, আজকের আয়াত), ১১৪ সূরার রিডার (আরবি, বাংলা উচ্চারণ, অর্থ, টীকা), ১৫ ক্বারীর অডিও প্লেয়ার, সার্চ, বুকমার্ক, সেটিংস ও ৩ থিম।

**এরপর:** নিচের "পরের কাজ" তালিকার ১ নম্বর (দৈনিক আমল ও দোয়া, **উৎস যাচাই দিয়ে শুরু**)।

## কাজের নিয়ম (মালিকের পছন্দ)
- **সব কথা বাংলা লিপিতে।** কোড ও কমিট ইংরেজিতে।
- মোবাইল আগে, UI হতে হবে ultra premium। ডিজাইন: পুরো অ্যাপ **নূর-এ-লাইল**, শুধু স্বাগতম পাতা **ফজর** (ক্যানভাস https://claude.ai/artifact/QzKXZrqbGiZ3HMZqSdNnu3, ছবি `design/options.png`)। বড় নতুন ডিজাইন হলে আগে দেখিয়ে অনুমোদন নিতে হবে।
- ধাপে ধাপে: কোড → টেস্ট → typecheck → lint → build → ব্রাউজারে প্রতিটি বাটন চেপে যাচাই → তারপর পরের ধাপ। যা পরীক্ষা হয়নি তা স্পষ্ট বলতে হবে।
- নিজে থেকে কমিট বা পুশ নয়।

## ভাঙা যাবে না
- কুরআন, হাদিস, দোয়ার লেখা **স্মৃতি থেকে বা হাতে টাইপ/কপি করে নয়**; শুধু ডেটা ফাইল থেকে স্ক্রিপ্টে (হাতে কপি করলে হরকতের ক্রম ও "য়" বদলে যায়)।
- `data/raw/` হাতে বদলানো নিষেধ। `public/data/` শুধু `npm run data:build` দিয়ে।
- নিজস্ব ধর্মীয় লেখা (নামাজ শিক্ষা, রমজান, ঘটনা) আলেম অনুমোদনের আগে প্রকাশ নয়।
- নমুনা বা বানানো ডেটা আসল অ্যাপে নয়; অসম্পূর্ণ ফিচারে "তৈরি হচ্ছে"।

## যা না জিজ্ঞেস করে করা যাবে না
নতুন ডেটা বা ফাইল ডাউনলোড (নাম, উৎস, সাইজ বলে অনুমতি), ডেপ্লয়, কমিট/পুশ, কাউকে মেইল।

## চালানো ও যাচাই
- `npm test` · `npm run typecheck` · `npm run lint` · `npm run build` (ফল `out/`)
- UI যাচাই **প্রোডাকশন বিল্ডে**, বিল্ট-ইন ব্রাউজারে: `preview_start {name: "noor-quran-static"}` → http://localhost:5361 (কনফিগ `~/Projects/.claude/launch.json`)। মাপ ৩২০×৫৬৮, ৩৯০×৮৪৪, ১২৮০×৮০০।
- ফাঁদ: পোর্ট ৩০০০-এর পুরোনো `next dev` একবার পুরোনো CSS দিয়েছিল। পাইথন প্রিভিউ সার্ভার মাঝে মাঝে `ERR_CONNECTION_RESET` দেয়; রিলোড করলে ঠিক হয়।
- Next.js 16: কোড লেখার আগে `node_modules/next/dist/docs/` দেখুন (AGENTS.md)।

## পরের কাজ (ক্রমানুসারে, PLAN §৮)
1. দৈনিক আমল, নামাজ-পরবর্তী আমল, দোয়া: **আগে উৎস যাচাই**; প্রতিটিতে রেফারেন্স, আরবি হাদিস-উৎসের সাথে স্বয়ংক্রিয় মিল; প্রকাশের আগে আলেম অনুমোদন
2. হাদিস (অনুবাদের স্বত্ব আগে)
3. অফলাইন/PWA, অডিও ডাউনলোড, কিবলা, তাসবিহ, হিজরি ক্যালেন্ডার
4. নামাজ শিক্ষা (**দুই পদ্ধতিই**: হানাফি ও সহিহ হাদিসভিত্তিক), রমজান, ঈদ, জানাজা, নবী-সাহাবি
5. রেঞ্জ রিপিট, আয়াত-কার্ড ছবি শেয়ার, পিঞ্চ-জুম
